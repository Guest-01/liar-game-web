## 🚧 v2 재작성 중

이 브랜치(`v2`)에는 **구현 코드가 없다.** 설계 문서만 있는 백지 상태다.

서비스 중인 v1은 [`v1.4.1`](https://github.com/Guest-01/liar-game-web/tree/v1.4.1) 태그에 있다.
배포는 `v*` 태그 푸시에만 걸리므로 이 브랜치 작업은 프로덕션에 영향이 없다.

### 왜 다시 만드는가

v1은 동작하지만 구조적 결함이 있었다.

- **호스트 브라우저가 게임 진행의 권위를 쥐고 있었다.** 호스트가 탭을 백그라운드로
  두면 타이머가 멈춰 게임 전체가 정지했다.
- **새로고침하면 게임에서 퇴출됐다.** `socket.id`를 플레이어 정체성으로 썼기 때문에
  재접속이 불가능했고, 라이어가 2초 끊기면 그 자리에서 게임이 끝났다.
- 상태 머신이 서버와 클라이언트에 이중으로 존재했고, 오케스트레이션의 절반이
  테스트 불가능한 소켓 핸들러에 있었다.

v2는 **서버 권위 + 세션 기반 재접속**을 전제로 다시 설계했고,
관전·연속 라운드·누적 점수를 새로 넣는다.

## 게임 규칙

- 4~10명. 한 명이 **라이어**, 나머지는 같은 **제시어**를 받는다.
- **일반 모드**: 라이어는 제시어 없이 유추해야 한다.
  **바보 모드**: 라이어도 자신이 라이어인지 모른다 (다른 단어를 받는다).
- 돌아가며 제시어를 한 줄로 설명하고, 토론해서 라이어를 지목한다.
- 라이어를 처형하면 시민 승. 단, **라이어가 제시어를 맞히면 역전승**.
